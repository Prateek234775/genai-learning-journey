# 📚 PDF Study Assistant

An AI-powered study assistant that lets you chat with your documents.

## Features
- Upload PDF or text documents
- Ask questions in natural language
- Get answers grounded in your documents
- Auto-generate MCQ quizzes
- Create flashcards for studying
- Export chat history

## Tech Stack
- LangChain + Groq LLaMA3 + FAISS + Streamlit

## How to Use
1. Click Initialize Assistant
2. Upload your document or use the demo
3. Start asking questions
